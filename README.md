# 3BLDTrainer
Standalone browser-based 3×3 and 3×3 Blindfolded (3BLD) speedcubing trainer featuring custom letter schemes, memo/execution timers, 2D/3D algorithm animations, and solve statistics.

Cube Trainer (3×3 & 3BLD) is a zero-dependency, single-HTML-file speedcubing practice suite built for both regular 3×3 speedsolving and 3×3 Blindfolded (3BLD) training:

- 3×3 Blindfolded Mode: Automatic edge/corner memo tracing with customizable letter schemes (Speffz & custom), cycle-break priority ranking, custom letter-pair mnemonics, buffer presets (Old Pochmann, M2, 3-Style), pseudo-swap parity handling, step-by-step 3D memo animation, and Kociemba-based step practice scrambles.

- 3×3 Speedsolving Mode: Full CFOP algorithm library (Cross, 41 F2L, 2-Look/1-Look OLL, 2-Look/1-Look PLL) with interactive 2D/3D previews, move animations, custom algorithm editing, and learning/finished status tracking.

- Timer, Stats & Customization: Split (memo + execution) and single-phase hold timers, Ao5/Ao12/Mean breakdowns with text & PNG export, and 11 themes with full local import/export support.
